# Buoyant Voyage
*Buoyant Voyage* is a game created for the 2025 *Australian STEM Video Game Challenge* by *Jaraph*.

Jaraph is comprised of two people, me (DanteGraet) and Quindocah.

## Fun Fact!
Unlike most repositories, where the repo is the game, *Buoyant Voyage* is contained within then “boteGame” folder, with “other” being used to share assets, audio files, and anything else related to development we both may have wanted access to.
